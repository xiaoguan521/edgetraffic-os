syapp 独立模式
==============

只安装 syapp 软件包、不接入控制台时，syapp 以独立模式运行，配置文件由管理员手工维护。

安装后已写入基线配置（/opt/syapp/conf/current -> releases/r000000）：
  - 基线安全设置、JSON 访问日志 /var/log/syapp/access.json、限速区域、常用代理头
  - 未匹配任何域名的请求直接断开；本机状态页 127.0.0.1:8081/__syapp_status

启动：
  systemctl enable --now syapp

添加站点：
  cp /opt/syapp/share/defaults/standalone-example.conf /opt/syapp/conf/current/conf.d/www.conf
  vi /opt/syapp/conf/current/conf.d/www.conf
  syapp -t && systemctl reload syapp

命令与参数与上游一致：syapp -t / -T / -s reload / -s reopen / -s quit / -v / -V。
建议始终使用 systemctl reload syapp 生效配置（不会中断现有连接），不要 restart。

接入控制台
----------
安装 syapp-agent 并注册（控制台“节点”页“添加节点”生成的命令）后，配置改由控制台发布，
手工改动会被标记为“配置被手动改动”，并在下一次发布时被替换。

  - 本机配置未改动过：直接注册即可。
  - 本机已有自定义配置：注册会被拒绝，以免配置被静默替换。可选择：
      1) 在控制台按站点重新录入（或使用规划中的“导入现有配置”功能）后，再注册；
      2) 确认由控制台接管：syapp-agent enroll ... -replace-local-config
         当前配置先备份到 /var/lib/syapp-agent/backups/standalone-<时间>.tar.gz（0600），
         在控制台首次发布之前，syapp 继续使用本机配置运行。

Based on NGINX Open Source (BSD-2-Clause)，详见 /opt/syapp/share/doc/NOTICE。
